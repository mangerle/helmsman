安全、无损、现代化的 Linux GRUB 管理工具

Helmsman 采用 100% 纯安全 Rust 与 GPUI 构建，以特权分离架构、AST 语法保真引擎与原子快照回滚取代传统 Grub Customizer，让每次引导调整与内核升级都从容可靠。

下载最新版本 (.deb / .AppImage) 查看源码仓库

特权分离与 Polkit 鉴权

桌面端以普通非特权用户运行，所有系统级写入均经由 D-Bus 系统总线与 PolicyKit 鉴权，按需激活后台守护进程。

无损引导排序

绝不劫持 /etc/grub.d/10_linux。采用原生 GRUB_DEFAULT 语义索引与受管 41_helmsman_custom 脚本，兼容系统内核升级。

AST 语法保真回写

将 /etc/default/grub 解析为抽象语法树，修改时 100% 保留原有注释、空白行、引号风格与键值顺序。

事务原子写入与快照回滚

每次修改提供 Unified Diff 审核、影响分析、磁盘空间预检与自动快照备份，失败可一键秒级还原。

GRUB 主题安全管理

支持本地压缩包导入与 HTTPS 在线下载，严格防范 Zip Slip 路径穿越与解压炸弹，内置壁纸与配色设置。

Ed25519 签名自更新

集成 shipup 自更新与启动崩溃自动回滚机制，所有发布包均经 Ed25519 签名与 SHA-256 校验。
